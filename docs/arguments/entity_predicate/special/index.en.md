# Special type

特殊类型的实体谓词，是无法通过实体选择器参数直接指定，而是通过实体选择器参数间接指定，或由实体选择器类型指定的实体谓词。

Entity predicates of the special type, refer to entity predicates that are not directly specified by entity selector parameters, but intermediately specified or specified by entity selector types.
