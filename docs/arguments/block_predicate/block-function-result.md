# `block-function-result()`：测试方块函数运行的结果但不实际修改方块

此[方块谓词](index.md)需要指定一个方块函数和方块谓词。谓词运行时，会先尝试运行方块函数并得到方块函数运行的结果（不会实际放置方块，也不会修改方块实体），然后检测方块函数运行的结果是否符合指定的方块谓词。

!!! warning
    此类方块谓词不能很好地处理好方块实体。在尝试获取方块函数运行的结果时，不会计算方块实体修改后的结果。

!!! info
    此类方块谓词引用了方块函数，而 [`if()`](../block_function/if.md) 等方块函数引用了方块谓词，所以此类方块谓词可用于制造方块谓词与方块实体间的跨注册表循环引用，并测试模组对跨注册表循环引用的处理能力。

## 语法

`#!python block-function-result(<方块函数>, <方块谓词>)`

## 数据结构

- `type`：此时为 `block_function_result`。
- `try_apply`：方块函数。
- `predicate`：谓词。
